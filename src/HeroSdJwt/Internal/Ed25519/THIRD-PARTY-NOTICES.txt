MODIFICATIONS FOR HEROSD-JWT
=============================

This port includes the following modifications:
- Namespace changed from Chaos.NaCl.Internal.Ed25519Ref10 to HeroSdJwt.Internal.Ed25519
- Uses System.Security.Cryptography.SHA512 instead of custom SHA512 implementation
- Adapted to work with PKCS#8 key formats for interoperability
- Minor style adjustments to match HeroSD-JWT code conventions

All cryptographic operations remain unchanged from the original implementation.
